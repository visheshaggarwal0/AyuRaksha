# AyuRaksha — UI/UX Design Brief

## 1. Design Direction

AyuRaksha should feel:

- authoritative;
- calm;
- trustworthy;
- modern;
- Indian without becoming ornamental;
- technical but approachable.

Avoid: - generic neon AI dashboards; - excessive gradients; - “legal
document” visual clutter; - stereotypical Ayurveda imagery everywhere.

The visual language should combine:

**Ayurvedic heritage + government-grade trust + modern AI tooling.**

## 2. Brand Personality

Keywords:

- Trustworthy
- Protective
- Precise
- Calm
- Intelligent
- Transparent

Tagline:

> **Protect. Comply. Innovate.**

Secondary:

> **Your intelligent guide to Ayurveda, IP & regulation.**

## 4. Typography

Primary:

- Inter for UI;
- Noto Sans Devanagari for Hindi;
- Noto Sans for multilingual fallback.

Scale:

| Name    | Size | Weight |
|---------|-----:|-------:|
| Display | 36px |    700 |
| H1      | 30px |    700 |
| H2      | 24px |    700 |
| H3      | 20px |    650 |
| Body    | 16px |    400 |
| Small   | 14px |    400 |
| Caption | 12px |    500 |

Mobile display sizes can reduce by 15–20%.

## 5. Spacing

Use an 8px base grid:

- 4px — micro;
- 8px — compact;
- 16px — standard;
- 24px — section;
- 32px — large;
- 48px — page;
- 64px — hero.

## 6. Radius

- Inputs: 10px
- Cards: 16px
- Dialogs: 20px
- Buttons: 10px
- Pills: 999px

## 7. Components

### Buttons

Primary: - filled green; - white text.

Secondary: - light surface; - green border/text.

Danger: - red only for destructive action.

### Cards

Use cards for: - assessments; - sources; - IP routes; - workflows.

Avoid cards inside cards unless necessary.

### Confidence badge

- High — green;
- Moderate — amber;
- Low — red.

Always accompany colour with text.

### Citation chip

Example:

`Patents Act · §3(p)`

Click opens source detail.

### Source card

Display: - authority; - document; - section; - date; - jurisdiction; -
support status.

## 8. Chat UX

Assistant messages should have a predictable structure:

1.  direct answer;
2.  why;
3.  jurisdiction;
4.  caveat;
5.  sources;
6.  next action.

Never dump raw retrieved passages into the chat.

## 9. Product Journey UX

Use a horizontal progress indicator on desktop and a compact step
indicator on mobile.

Each question should answer:

> “Why are you asking me this?”

via a small optional info tooltip.

## 10. Empty States

Example:

> **Start your first IP journey**  
> Tell AyuRaksha about your Ayurvedic product and we’ll map the likely
> protection and compliance pathways.

## 11. Trust UX

Always make these visible where relevant:

- “Information, not legal advice.”
- source authority;
- source date/version;
- confidence;
- missing information.

The product should never hide uncertainty behind polished language.

## 12. Dark Mode

Dark mode should not simply invert colours.

Use: - deep green-black background; - slightly lighter surfaces; - green
primary accents; - amber for attention; - high-contrast white text.

Avoid pure black and pure white.

## 13. Visual Motif

A subtle motif inspired by: - leaf veins; - knowledge graph nodes; -
protective circles.

Use sparingly in: - splash screen; - empty states; - section headers.

Do not use decorative motifs behind legal text.
